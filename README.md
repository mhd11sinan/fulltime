# Fulltime

Rate Champions League matches and players, and share your top fours with friends.

## Run locally
Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

Then visit http://localhost:8000. Ratings are saved in your browser. The Friends tab needs a backend (see CLAUDE.md).

## Host on GitHub Pages
See [HOSTING.md](HOSTING.md).

## Use with Claude Code
    cd fulltime
    claude

Claude Code will read `CLAUDE.md` for the project context and roadmap.
